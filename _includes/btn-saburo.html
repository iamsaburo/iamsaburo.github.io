{%- comment -%} Параметри: label — текст кнопки (обов'язково) visual — тип у спокої: "outline", "white", "rainbow" (за замовчуванням outline) hover — тип при наведенні: "outline", "white", "rainbow" або false (не змінювати) icon_visual — назва іконки Material Icons Round для стану спокою, або "none" icon_hover — назва іконки при наведенні, або "none" width — ширина в px (або "auto"; за замовч. auto) height — висота в px (за замовч. 48) radius — радіус заокруглення в px (за замовч. 10) href — URL для посилання; якщо не задано – тег
